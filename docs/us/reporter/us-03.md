
## US-03: Track Issue Status

**As a** reporter (student or university staff member),  
**I want to** view the current status of my reported issues,  
**So that** I can understand the current state of their resolution.

**Related Requirements:** FR-17

### Acceptance Criteria

**AC 1: View the current status of a reported issue**

Given the reporter is authenticated  
And the reporter has submitted a report  
When the reporter views the report details  
Then the system shall display the current status of the associated issue.

**AC 2: View an updated issue status**

Given the status of a reported issue has been changed  
When the reporter views the report details  
Then the system shall display the latest status.

**AC 3: Prevent unauthorized status modification**

Given the reporter is viewing one of their reports  
When the reporter attempts to modify the status of the associated issue  
Then the system shall prevent the modification.

**AC 4: View the status of multiple reported issues**

Given the reporter has submitted multiple reports  
When the reporter views their submitted reports  
Then the system shall display the current status of each associated issue.
