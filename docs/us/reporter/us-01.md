
## US-01: Submit an Issue Report

**As a** student or university staff member,  
**I want to** submit a report containing a description and relevant information about a university issue,  
**So that** the responsible personnel can review and address it.

**Related Requirements:** FR-01, FR-02, FR-03, FR-04, FR-05, FR-06

### Acceptance Criteria

**AC 1: Successfully submit a report**

Given the user is authenticated  
And the user has opened the report submission form  
When the user provides a description  
And submits the report  
Then the system shall create a new report  
And associate it with an initial issue status  
And display a confirmation message.

**AC 2: Submit a report with additional information and images**

Given the user is authenticated  
And the user has opened the report submission form  
When the user provides a description, category, and location  
And attaches one or more supported images  
And submits the report  
Then the system shall save all provided information  
And associate the images with the report  
And make the information available when viewing the report.

**AC 3: Submit a report without optional information**

Given the user is authenticated  
And the user has opened the report submission form  
When the user provides a description  
And leaves the category, location, and image attachments unspecified  
And submits the report  
Then the system shall accept the report  
And associate it with an initial issue status.

**AC 4: Submit a report without a description**

Given the user is authenticated  
And the user has opened the report submission form  
When the user attempts to submit the report without a description  
Then the system shall reject the submission  
And display a validation message indicating that a description is required.

**AC 5: Attach an unsupported image**

Given the user is submitting a report  
When the user selects an image in an unsupported format  
Then the system shall reject that image  
And display an appropriate error message.

**AC 6: Submit a report with multiple images**

Given the user is submitting a report  
When the user attaches multiple supported images  
And submits the report  
Then the system shall associate all attached images with the submitted report.
