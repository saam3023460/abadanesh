Admin Requirements


1. Overview


The Admin is responsible for managing the Abadanesh system, its staff accounts, permissions, and basic system information.


The Admin does not directly handle submitted reports or perform technical tasks.


2. Admin Responsibilities




Create, edit, and deactivate Coordinator and Technician accounts.


Assign roles and access permissions to staff members.


Assign Technicians to Service Units.


Create and manage report Categories.


Create and manage university Locations.


Create and manage Service Units.


View overall system statistics and activity.




3. Business Rules




Staff members cannot register themselves.


Only Admin can create Coordinator and Technician accounts.


Admin assigns a role to each staff account.


Each Technician must be assigned to a Service Unit.


Reporters can register automatically using their phone number and OTP.


Coordinators are responsible for reviewing and managing reports.


Technicians are responsible for carrying out technical tasks.


Admin manages the system but does not directly handle reports.




4. Scope


Admin management features are planned for a future release. Their exact release and implementation details will be decided by the team.
