
# Abadanesh

## About the Project

**Abadanesh** is a university issue management platform designed to help resolve problems reported by students and university staff.

The system provides a platform for reporting and managing issues related to university infrastructure, electrical systems, technical equipment, sanitation, campus facilities, and other university services. It also allows users to submit suggestions for improving the university environment.

Abadanesh focuses on the entire problem-solving process, enabling coordinators to review reports, assign them to responsible departments, monitor their progress, and follow up until the issues are resolved.

### User Stories Organization

The `docs/us/` directory contains user stories grouped by actor or functional category:

- **admin/** – User stories related to system administration and user management.
- **system/** – User stories describing system-wide behavior.
- **technician/** – User stories related to handling assigned issues and updating their progress.
- **coordinator/** – User stories related to reviewing reports, assigning issues, and monitoring resolution.
- **reporter/** – User stories related to submitting reports, tracking issues, and receiving notifications.
